# Antigravity Integration

1. Copy the five command files in this directory into your project's Antigravity
   commands location per Antigravity's own docs.
2. Copy `context-templates/AGENTS.md` (from the kit root) into your project root.
3. Copy `plugin/skills/` (from the kit root) into `AgentSkills/` in your project
   root, preserving the directory structure, so the command files' relative
   references resolve.
4. Invoke `/plan-analysis 19`, `/start-coding 19`, `/testing 19`, `/fleet 19`, or
   `/rules-check-drift` (no version argument).
