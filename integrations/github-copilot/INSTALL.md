# GitHub Copilot CLI/Agent Integration

1. Copy `agents/odoo-dev.agent.md` into your project's `.github/copilot/agents/`.
2. Copy `context-templates/copilot-instructions.md` (from the kit root) into
   your project's `.github/copilot-instructions.md`.
3. Copy `plugin/skills/` (from the kit root) into your project, preserving the
   directory structure.
4. Launch the Copilot CLI/Agent with this profile for autopilot-style sessions
   covering the same `/plan-analysis` → `/start-coding` → `/testing` lifecycle.
