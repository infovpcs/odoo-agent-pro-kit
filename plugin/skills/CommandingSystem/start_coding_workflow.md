# /start-coding Workflow

Complete step-by-step execution guide for the `/start-coding (17|18|19)` command.

---

## STEP 1: Parse & Pre-Flight Gate Check

```
User runs: /start-coding 19
→ version = 19
→ Ask for module name if not provided
```

**Check 1 — PRD files exist:**
```python
# 1. Resolve target path (Phase 20.5)
# Use version-specific custom addons path based on {version}
custom_keys = {
    "17": "ODOO17_CUSTOM_ADDONS",
    "18": "ODOO18_CUSTOM_ADDONS",
    "19": "ODOO_CUSTOM_ADDONS"
}
key = custom_keys.get(str(version))
target_root = os.getenv(key) or os.getenv("ODOO_CUSTOM_PATH") or os.getcwd()
module_dir = os.path.join(target_root, module_name)

    os.path.join(module_dir, "docs/requirements.md"),
    os.path.join(module_dir, "docs/design.md"),
    os.path.join(module_dir, "docs/tasks.md"),
    os.path.join(module_dir, "docs/module_meta.md"),

        raise GateError(f)
```

**Gate failure output:**
```

Missing: docs/tasks.md

  1. Run /plan-analysis {version} for this module (auto-routed)
  2. Generate missing PRD files
```


## STEP 4: Task Execution Loop

For each `[ ]` task in `docs/tasks.md`, execute:

### 4a. Load task context
```python
current_task = get_next_incomplete_task(tasks_md)
print(f"📝 Working on: {current_task.title}")

# Load relevant sub-skill for this task type
if "model" in current_task.title.lower():
    read_skill("Agents/OdooServerSide/SKILL.md")
elif "view" in current_task.title.lower() or "owl" in current_task.title.lower():
    read_skill("Agents/OdooWebAgent/SKILL.md")
elif "website" in current_task.title.lower():
    read_skill("Agents/OdooWebsiteAgent/SKILL.md")
```

### 4b. Implement the task
Following Odoo{V}CodingStandard rules:

**Odoo 19 standards:**
- Models: `_inherit`, `@api.constrains` (not `_sql_constraints`), `self.env.context`
- Views: `<list>` (not `<tree>`), direct attributes (not `attrs`), `<chatter>` tag
- Controllers: `type='jsonrpc'` (not `type='json'`)

**Odoo 18 standards:**
- Views: `<list>` supported, `attrs` deprecated
- Security: `ir.model.access.csv` required

**Odoo 17 standards:**
- Views: `<tree>` still valid
- Keep backward-compatible patterns

### 4c. Validate code quality gates
```
Before marking any sub-task complete, verify:
  [ ] No field redefinitions from parent model
  [ ] Real implementation (not stubs or placeholders)
  [ ] Proper error handling with try/except
  [ ] Logging with _logger
  [ ] Type hints on functions
  [ ] Docstrings
```

### 4d. Run backend tests via Odoo_Custom_Backend_Testing skill

```
read AgentSkills/Odoo_Custom_Backend_Testing/SKILL.md
```

**Pre-test: Ensure PostgreSQL and Odoo are running**
```bash
# Workspace path — resolve from env var first, then default to $HOME/odoo-workspaces
# macOS: $HOME = /Users/<name>   Linux: $HOME = /home/<name> or /root
ODOO_WORKSPACES_ROOT="${ODOO_WORKSPACES_ROOT:-$HOME/odoo-workspaces}"
WORKSPACE_PATH="${WORKSPACE_PATH:-$ODOO_WORKSPACES_ROOT/${version}_workspace}"

# Start PostgreSQL — cross-platform
if command -v systemctl &>/dev/null && systemctl list-units --type=service 2>/dev/null | grep -q postgresql; then
    # Linux (Ubuntu/Debian/RHEL) — PostgreSQL managed by systemd
    sudo systemctl start postgresql 2>/dev/null || sudo service postgresql start 2>/dev/null || true
elif command -v pg_isready &>/dev/null; then
    # macOS (Homebrew) or compiled postgres — pg_ctl fallback
    pg_isready -h localhost -p 5432 || {
        PGDATA="${PGDATA:-$(find /usr/local/var /var/lib/postgresql -maxdepth 2 -name "PG_VERSION" 2>/dev/null | head -1 | xargs dirname 2>/dev/null)}"
        [ -n "$PGDATA" ] && pg_ctl -D "$PGDATA" start || echo "⚠️ Cannot auto-start PostgreSQL — start it manually"
    }
fi

# Start Odoo if not running (detect port from root odoo.conf first)
ODOO_PORT=$(grep "^xmlrpc_port" "$WORKSPACE_PATH/odoo.conf" | awk '{print $NF}')
curl -s "http://localhost:${ODOO_PORT}/web/health" | grep -q "pass" || \
  (WORKSPACE_PATH="$WORKSPACE_PATH" bash "$WORKSPACE_PATH/manage_modules.sh" start \
   > /tmp/odoo${version}_server.log 2>&1 & sleep 18)
```

**Install/update the module — CRITICAL patterns:**
```bash
# ALWAYS invoke via `bash` with WORKSPACE_PATH set — DO NOT call ./manage_modules.sh directly
# Reason: macOS default shell is zsh (lacks bash 4+ features); on Linux bash is default but
# explicit `bash` invocation is still the portable, safe choice on any platform

cd "$WORKSPACE_PATH"

# If first install:
WORKSPACE_PATH=$(pwd) bash manage_modules.sh install {module_name}

# If already installed (re-run after code change):
WORKSPACE_PATH=$(pwd) bash manage_modules.sh update {module_name}

# NOTE: update STOPS the Odoo server — wait and restart:
sleep 3
curl -s "http://localhost:${ODOO_PORT}/web/health" | grep -q "pass" || \
  (WORKSPACE_PATH=$(pwd) bash manage_modules.sh start > /tmp/odoo${version}_server.log 2>&1 & sleep 18)
```

**Run the RPC test scripts:**
```bash
# Use workspace venv Python for xmlrpc tests
.venv/bin/python3 {module_name}/scripts/test_workflows.py \
    --url "http://localhost:${ODOO_PORT}" \
    --db {db_name} \
    --password admin
```

**Odoo 19 xmlrpc breaking changes (from Phase 25 lessons):**
```
1. execute_kw(db, uid, pw, model, method, [args], {kw}) — args and kw must be SEPARATE positional params
2. Action methods must return True (not None) — Odoo 19 raises Fault on None return
3. Security: res.groups category_id → privilege_id via new res.groups.privilege model
4. Search view: <group> no longer accepts 'expand' or 'string' attributes
5. manage_modules.sh must be invoked via explicit `bash` on ALL platforms — macOS default shell
   is zsh (lacks bash 4+ `${var^^}`); on Linux use `bash` for portability even though bash is default
```

**Test attempt logic:**
```python
max_attempts = 3
for attempt in range(1, max_attempts + 1):
    test_result = run_backend_tests(module_name, version)
    if test_result.passed:
        break
    else:
        print(f"⚠️  Test attempt {attempt}/{max_attempts} failed:")
        print(test_result.error)
        # Auto-fix the error and retry
        fix_error(test_result.error)
        
if not test_result.passed:
    # Surface to user after 3 failures
    print("❌ Backend tests failed after 3 attempts. User input needed.")
    print(f"Error: {test_result.error}")
    exit()
```
