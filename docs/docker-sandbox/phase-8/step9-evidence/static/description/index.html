Pricelist Rule Remove and Edit

Manage pricing rules from the pricelist form and safely remove explicitly matched rules while retaining Odoo's standard pricing behavior.

Odoo 18.0 Community LGPL-3 Sales

Focused pricelist management

Rule count at a glance

A smart action on each pricelist shows the number of visible pricing rules. Counts are computed in batches for efficient multi-record use.

Scoped native views

Open the standard Odoo 18 pricelist-rule list and form views, already filtered to the active pricelist and ready to create rules in the correct scope.

Safe programmatic removal

Delete rules only through explicit, validated criteria. Every operation is forced into the supplied pricelist scope and uses the standard ORM.

Standard price fallback

After a matching rule is removed, subsequent Odoo price computations naturally select the remaining applicable rule—without a custom pricing engine.

How it works

  1. Open a standard Sales pricelist.
  2. Select the Pricelist Rules smart action.
  3. Edit, create, or remove rules using Odoo's native rule views.
  4. New or explicitly repriced draft transactions use the remaining applicable rules.

Security by design

  • No additional access-control lists or elevated privileges are introduced.
  • Standard Odoo ACLs, record rules, company boundaries, constraints, and unlink hooks remain in force.
  • Empty, unsupported, or unbounded deletion criteria are rejected.
  • Confirmed and historic business documents are not silently repriced.

Installation

  1. Place edit_remove_pricelist_rule in a custom addons path.
  2. Update the Apps list.
  3. Search for Pricelist Rule Remove and Edit and install it.

Dependency: Sales (sale). No Odoo Enterprise addon is required.
